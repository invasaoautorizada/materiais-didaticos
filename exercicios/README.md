# Exercícios e Atividades

Espaço destinado à disponibilização de exercícios,
desafios e atividades práticas desenvolvidos pelo
Invasão Autorizada.

Os conteúdos têm como objetivo estimular a prática,
o raciocínio e a aplicação dos conhecimentos
adquiridos nos estudos.

## Conteúdos

- Listas de exercícios
- Questionários e simulados
- Desafios técnicos
- Estudos de caso
- Atividades práticas
